# Scroll-Driven Hero Section Animation

A premium scroll-driven hero animation built for the frontend assignment using:

- HTML5
- CSS3
- Vanilla JavaScript
- GSAP + ScrollTrigger
- Responsive layout
- GitHub Pages compatible static hosting

## Run locally

Open `index.html` directly in a browser, or use VS Code Live Server.

## GitHub Pages

1. Create a GitHub repository.
2. Upload `index.html`, `style.css`, `script.js`, and `assets/fizz-car.svg`.
3. Go to **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select `main` and `/ (root)`.
6. Save and wait for GitHub Pages to publish.

Your URL will be:

`https://YOUR-USERNAME.github.io/YOUR-REPOSITORY/`

## Assignment requirements covered

- Above-the-fold hero section
- Letter-spaced headline
- Four impact statistics
- Staggered page-load animation
- Scroll-position-driven visual movement
- Transform-based animation
- GSAP ScrollTrigger with scrub interpolation
- Responsive mobile layout
